# OurTimes

CST8319 — Assignment 3 (Demo 3), Group 2

## Overview
OurTimes is an Android application for creating, viewing, editing and deleting personal memories. Users can save notes, photos, dates, times, locations and star ratings. Memory records are stored using Room (SQLite), and photos are saved in internal application storage.

## Technologies

Component	Technology

IDE:	Android Studio

Application language:	Java 11 source compatibility

User interface:	XML layouts, Android Views and Material components

Architecture:	Model–View–ViewModel (MVVM) with Repository

Database:	Android Room 2.7.2 / SQLite

UI state and observation:	ViewModel and LiveData 2.9.2

Memory list:	RecyclerView 1.4.0

Navigation:	Android Navigation 2.9.3

Photo selection:	Android Photo Picker

Build configuration:	Gradle Kotlin DSL

Minimum SDK:	API 24 (Android 7.0)

Target SDK:	API 36

Test device:	Pixel 7 Android emulator

Application ID:	com.example.ourtimes
